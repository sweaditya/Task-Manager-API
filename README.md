# Task Manager API

A beginner-friendly backend project built using Node.js and Express.js. This project is being developed step by step to practice backend fundamentals and REST API development.

## Current Features

- Express server setup
- Root route (`GET /`)
- JSON body parsing middleware
- Custom middleware for logging incoming requests
- Basic HTTP request and response handling

## Tech Stack

- Node.js
- Express.js
- JavaScript
- npm

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your system.

Check their versions:

```bash
node -v
npm -v
```

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sweaditya/task-manager-api.git
   ```

2. Navigate to the project directory:

   ```bash
   cd task-manager-api
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   node server.js
   ```

5. Open the following URL in your browser:

   `http://localhost:3000`

Expected response:

```text
Task Manager Api is Running
```
